# Security policy

LAPMETRY is an independently maintained fan project and is not affiliated with Formula 1, FIA, teams, drivers, or any data provider.

## Reporting a vulnerability

Please **do not** publish exploit details, credentials, or a working proof of concept in a public GitHub issue.

If GitHub's private vulnerability reporting is enabled for this repository, use the **Security** tab and choose **Report a vulnerability**.

If private reporting is not available, contact the repository maintainer through their GitHub profile to arrange a private reporting channel before sending details. No dedicated security email address is published at this time.

When reporting, provide affected endpoints or files, impact, reproduction requirements, and a suggested mitigation if available. Do not include real user secrets.

## Response and scope

This is a small, volunteer-maintained project. There is no guaranteed response-time SLA, bug bounty, or paid security program. The maintainer will prioritize credible reports according to severity and reproducibility.

Only test systems and accounts you own or are expressly authorized to assess. Avoid denial-of-service testing, accessing third-party data, or probing upstream services (including OpenF1) without authorization.

Security fixes should be reviewed and validated before public disclosure. Dependencies and deployed configurations may differ from the development branch.
