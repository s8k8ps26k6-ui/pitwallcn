# LAPMETRY 3.0 设计审查

**评审状态：待用户明确批准。** 适用范围为 `/home-next`，以下控件规则可供其他页面评审参考。是否推广需逐页决定。评审基线为 PR #69 的 `77d2cd0`。

## 控件规则

| 层级 | 规则 |
|---|---|
| 主操作 | 「当前比赛周」是地球场域唯一实底强调动作。切角取自赛道工程图的折线语言；箭头辅助识别入口，文字承担含义。 |
| 视角 | 全球和欧洲共用窄轨。选中同时有底线、底色及 aria-pressed。赛事节点保留地理锚点、引线和站次编号。 |
| 导航 | 赛历、Live、结果是文本站点入口。站点索引提供全部路由与不依赖地球的选站入口。 |
| 面板 | 正式赛事名作标题，城市与站次作定位数据。移动端手柄与箭头是同一双状态动作的两个入口；桌面使用有明确文字的折叠按钮。 |
| 字体与间距 | 显示字用于赛事名，等宽字用于站次、坐标和时间，界面操作用正文体。以 4、8、16、24、32px 建立对齐节奏。 |
| 命中与可访问性 | 主要移动控件使用 44px 命中区。空间节点保持密集布局，另提供常规尺寸的原生选站入口；需真机核对节点在投影后的命中尺寸。焦点使用清晰外框，状态同时以文字、几何标记或 ARIA 表达。 |
| 动效 | 保持 220ms 吸附过渡和拖动时的直接反馈。减少动态效果偏好下关闭过渡。保留展开后的独立内容滚动。 |

## 产品交互审查

| 证据与问题 | 影响 | 改动及复查 |
|---|---|---|
| 基线把比赛周与全球、欧洲放在同一视角组 | 入口含义混淆 | 独立主操作，视角组仅包含视角切换。复查三个动作的键盘顺序及当前赛事恢复。 |
| 基线索引选站后卸载 select，键盘焦点无返回路径 | 后续按键位置不明确 | 选站和 Escape 后返回索引按钮。 |
| 基线进度条依据已过计划开始时间着色 | 容易理解为实时完成进度 | 移除进度条，保留逐节计划时间和真实数据可用性。 |
| 基线手柄 30px、箭头 36px | 单手操作更容易误触 | 两者提升至 44px，检查短屏、长赛事名与安全区。 |

## 视觉审查

| 证据与问题 | 影响 | 改动及复查 |
|---|---|---|
| 基线场域有三个同权矩形操作 | 入口没有视觉重心 | 使用切角强调、低对比视角轨与文本索引三种几何。 |
| 地球定位和面板都把城市当标题 | 信息重复，正式赛事名被压到次级 | 地球保留地理定位，面板强调正式赛事名。 |
| 节点与地表的叠加对比依赖真实渲染 | 静态 CSS 审阅无法证明各种地表背景上的可读性 | 增加首页节点 hover 与焦点反馈。保留真实 WebGL 视觉审查项，包括欧洲密集节点和手柄对地球的遮挡。 |

## 技术审查与审批机制

工程门槛继续运行 build、typecheck、lint、单测、可用环境下的 E2E 和差异检查。审查时分别记录产品交互、视觉和工程三类结果，每项包含环境、证据、影响、建议与状态。截图只记录观察到的状态，不能授予视觉批准。真实 Safari 手势、WebGL 地球首帧与 Canvas 连续性仍沿用架构报告中的待测项，需重新核验本版本。

设计批准应由用户针对指定提交和预览明确给出。每轮保留原型版本与问题记录。若用户否决方向，先确定失效的是主入口、空间层级、控件语言或布局，再给出可对比的新方向，局部修补仅用于明确的单点问题。
